# Ход конём

Небольшой браузерный тренажёр, который показывает допустимые ходы шахматного коня на доске 8 × 8.

## Запуск

Откройте `index.html` в браузере. Сборка, установка зависимостей и сервер не требуются.

## Как играть

- Нажмите любую клетку, чтобы поставить на неё коня и увидеть возможные ходы.
- Нажмите подсвеченную клетку, чтобы переместить коня. Счётчик учитывает только такие ходы.
- Нажмите «Начать заново», чтобы очистить доску и сбросить счётчик.
- Стрелками на клавиатуре можно перемещать фокус по клеткам; Enter или пробел выбирает клетку.

Правила ходов реализованы как восемь смещений коня с проверкой границ доски. Для корректного открытия проекта нужен современный браузер с поддержкой JavaScript.
